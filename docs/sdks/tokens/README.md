# Tokens

## Overview

Operations related to API tokens

### Available Operations

* [getTokens](#gettokens) - Get tokens
* [deleteToken](#deletetoken) - Delete token

## getTokens

Returns a list of first-party API tokens for your organization. Requires admin access.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="getTokens" method="get" path="/tokens" -->
```typescript
import { OpalMcp } from "opal-mcp";

const opalMcp = new OpalMcp({
  bearerAuth: process.env["OPALMCP_BEARER_AUTH"] ?? "",
});

async function run() {
  const result = await opalMcp.tokens.getTokens({
    cursor: "cD0yMDIxLTAxLTA2KzAzJTNBMjQlM0E1My40MzQzMjYlMkIwMCUzQTAw",
    pageSize: 200,
    userId: "29827fb8-f2dd-4e80-9576-28e31e9934ac",
  });

  console.log(result);
}

run();
```

## deleteToken

Deletes a first-party API token. Admins can delete any token. Non-admins can only delete their own tokens when the organization allows all users to create API tokens.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="deleteToken" method="delete" path="/tokens/{token_id}" -->
```typescript
import { OpalMcp } from "opal-mcp";

const opalMcp = new OpalMcp({
  bearerAuth: process.env["OPALMCP_BEARER_AUTH"] ?? "",
});

async function run() {
  await opalMcp.tokens.deleteToken({
    tokenId: "f454d283-ca87-4a8a-bdbb-df212eca5353",
  });


}

run();
```
