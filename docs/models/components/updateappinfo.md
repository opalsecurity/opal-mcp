# UpdateAppInfo

Information needed to update an app. Currently supports only Push-only
apps (`CUSTOM`) and Custom Connector apps (`CUSTOM_CONNECTOR`).

## Example Usage

```typescript
import { UpdateAppInfo } from "opal-mcp/models/components";

let value: UpdateAppInfo = {
  visibility: "GLOBAL",
  importVisibility: "GLOBAL",
};
```
