# AgentActivityClientSettings Object
### Description
How a client should send batched agent activity for this organization.

## Example Usage

```typescript
import { AgentActivityClientSettings } from "opal-mcp/models/components";

let value: AgentActivityClientSettings = {
  batchWaitSeconds: 4187.26,
  maxEventsPerRequest: 744138,
  maxBytesPerRequest: 100592,
  maxRequestsPerSecond: 1092.01,
  burstRequests: 545695,
  cacheSeconds: 532253,
};
```
