# CreateCampaignConfigurationInfo

Configuration to apply when creating a campaign. `query` is required; other omitted fields use defaults.

## Example Usage

```typescript
import { CreateCampaignConfigurationInfo } from "opal-mcp/models/components";

let value: CreateCampaignConfigurationInfo = {
  query: {
    principalFilter: {
      entityTypes: [
        "USER",
      ],
    },
  },
  allowSelfReview: false,
  endDate: new Date("2026-09-30T00:00:00Z"),
  timezone: "America/Los_Angeles",
};
```
