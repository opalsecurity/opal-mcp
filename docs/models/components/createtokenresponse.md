# CreateTokenResponse

The created API token. `signed_token` is the secret credential and is
only returned once at creation time.


## Example Usage

```typescript
import { CreateTokenResponse } from "opal-mcp/models/components";

let value: CreateTokenResponse = {
  token: {
    tokenId: "f454d283-ca87-4a8a-bdbb-df212eca5353",
    createdAt: new Date("2022-01-23T04:56:07Z"),
    tokenLabel: "My API Token",
    creatorUserId: "d4a7d928-783e-4599-8ec6-088d635a5bcc",
    userId: "d4a7d928-783e-4599-8ec6-088d635a5bcc",
    accessLevel: "READ_ONLY",
  },
  signedToken: "opal_pat_abc123...",
};
```
